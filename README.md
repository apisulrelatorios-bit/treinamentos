# Portal de Treinamentos Apisul

Primeira versão do portal web criado a partir da estrutura do relatório Power BI "Treinamentos Apisul".

## Arquivos

- `index.html` — estrutura da página
- `style.css` — identidade visual, layout e responsividade
- `script.js` — filtros, busca e player de vídeo
- `assets/` — imagens extraídas do PBIX

## Vídeos

Os vídeos estão apontados para o repositório público:

https://github.com/apisulpowerbi-web/videosApisul

O site usa as URLs `raw.githubusercontent.com` para carregar os MP4 diretamente no player.

## Como usar

Abra `index.html` em um navegador moderno.

Para publicar, a pasta inteira pode ser hospedada em GitHub Pages, Netlify, Vercel ou outro serviço de hospedagem estática.
